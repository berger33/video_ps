# video_ps

Pipeline Python (VÍDEO 3) para gerar animação curta (~60s) de proliferação
surreal estilo Cyriak: uma raposa que se duplica progressivamente em um
campo verde, com sincronia macro (RMS) e micro (onsets) à trilha.

- FASE 0 — Brief de conceito: [`fase0_brief.md`](fase0_brief.md)
- FASE 1 — Assets + matting: [`fase1_report.md`](fase1_report.md) · rebuild: `python3 scripts/build_clips.py`
- Desenvolvimento em fases com aprovação humana obrigatória entre cada uma.
